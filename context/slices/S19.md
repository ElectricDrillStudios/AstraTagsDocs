- Migration guidance does not equate legacy Framework tag references with standalone package references

Follow the plan's completion protocol: update navigation, coverage, image needs, this report, and the state. Register unavailable checks explicitly. If interrupted or blocked, record the exact unfinished acceptance criteria and the next concrete action.
